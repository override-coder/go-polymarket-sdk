# Combo WebSocket 生命周期

Read(ctx) 仍要求单读协程调用，遵循 Gorilla 的 one-reader 约定。
取消会同步关闭该次 Read 捕获的连接，等待底层读取退出后返回 ctx.Err()。
读错误也会清理对应连接；旧连接的清理不会影响新连接。

Connect 先在新 socket 上写入认证消息，再安装连接；写入失败或在认证期间取消会关闭该 socket。
连接替换后关闭旧 socket。Connect 成功表示认证消息已写出，不代表服务端已认证成功；
调用方仍须读取和判断认证响应。

Close 可以中断正在进行的读写。写入互斥与连接状态锁分离，防止阻塞写入占用状态锁，
从而阻止取消/关闭。取消后的连接不可复用，需重新 Connect。
这些变更不增加自动重连或业务重试，现有 requester/maker 消息协议保持不变。
